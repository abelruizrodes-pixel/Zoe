# Amarilnta Selmanai · Landing page

Multilingual personal landing page (DE · FR · EN · ES · LB · PT) for the Luxembourg job market.

- `index.html` – page structure (all texts use `data-i18n` keys)
- `styles.css` – navy & gold visual design
- `i18n-*.js` – translations (6 languages)
- `app.js` – language selector (top-left), scroll animations
- `cv.html` – A4 one-page CV (print / save as PDF)

Open a specific language directly with `?lang=de`, `?lang=fr`, `?lang=en`, `?lang=es`, `?lang=lb` or `?lang=pt`.
